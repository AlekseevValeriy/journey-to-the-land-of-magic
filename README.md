# Journey to the Land of Magic

JRPG бродилка по острову и подземельям с целью сбежать

## Технологии

![Python](https://img.shields.io/badge/-Python-F9DC3E.svg?logo=Python&style=flat)
![PyGame](https://img.shields.io/badge/PyGame-2D8C3C)

## Возможности

- Процедурная генерация острова и подземелий
- Система улучшения персонажа
- Сохранение прогресса
- Удобная настройка игры

## Установка

```bash
git clone https://github.com/AlekseevValeriy/journey-to-the-land-of-magic.git
cd journey-to-the-land-of-magic
```

## Использование

```bash
cd src
cd module
python main.py
```
